# 日晷 DAYDIAL · 设计简报

## 1. 题目

**日晷 Daydial** 是一个本地优先的 24 小时日计划工具。它把一天画成一个圆：每一段安排是圆上的一段弧，颜色代表节奏，红色指针代表此刻。右侧的清单是圆盘的“账本”，负责精确编辑与无障碍访问。

- **使用者**：习惯按时间段工作、需要一眼看见一天结构的人。
- **主要任务**：快速放下一段安排、看清一天的重心、在计划变化时立刻调整。
- **使用场景**：桌面浏览器为主，手机可单手查看与添加；数据只存在本机。
- **网站性质**：单页静态应用，无后端、无账号、无追踪。

## 2. 设计概念

**一天不是一张列表，是一个圆。**

日晷是古代用影子读时间的仪器。这个网站借用“仪器”而不是“仪表盘”的语言：刻度、指针、圆环、精确对位。页面不靠营销首屏，打开就是工具本身。圆盘是唯一的视觉主角，其余部分保持安静。

## 3. 视觉系统

### 颜色

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `--paper` | `#E7E7E1` | `#111512` | 冷调骨白纸面 / 夜间底 |
| `--ink` | `#151A16` | `#ECEBE4` | 主文字、刻度 |
| `--muted` | `#596157` | `#A7AEA4` | 次要文字 |
| `--red` | `#C22F22` | `#FF6A55` | 此刻、主操作、错误；只做功能色 |
| `--cat-focus` | `#2846C8` | `#8EA2FF` | 深度工作 |
| `--cat-meet` | `#7C3F5E` | `#E7A3BC` | 会议 |
| `--cat-life` | `#4F6A4F` | `#9BBF96` | 生活 |
| `--cat-rest` | `#8A5A16` | `#E3B15F` | 休息 |
| `--line` | `rgba(21,26,22,.16)` | `rgba(236,235,228,.16)` | 分隔线、刻度 |

纸面不是暖奶油色，红色不是装饰色。红色只出现在“现在”、主按钮和错误状态，因此它始终意味着“正在发生”或“需要行动”。

### 字体

- **Bricolage Grotesque**：拉丁字母、数字、品牌字。带一点手工感，但不是常见的几何无衬线。
- **Songti SC / STSong / SimSun**：中文大字号与日期，衬线带来“刻度/印刷”的气质。
- **PingFang SC / Microsoft YaHei**：中文正文与控件，保证小字号可读。
- **IBM Plex Mono**：只用于时间、日期数字和极少量数据，承担“仪表读数”的角色。

字号遵循 1.25 左右的比例：10 / 11 / 12 / 14 / 16 / 20 / 25 / 31 / 39 / 49 / 61 / 76。10–11px 只用于元数据、刻度和时间副行；正文 12px 起，主体 16px，行高 1.6；中文展示字行高 1.1。所有小字都按 4.5:1 校准，不用透明度压暗。

### 布局

不对称 62 / 38 分栏。左侧圆盘是主视觉，右侧清单是操作区。两者之间用一条极细的竖线和顶部的小十字标记连接，像一张测绘图纸，而不是卡片拼贴。

圆盘以 **06:00 为顶部**，顺时针走到次日 06:00。这是有意的“一天从早晨开始”约定：00:00 因此落在 **9 点方向**，06:00 在正上方，12:00 在右侧，18:00 在底部；刻度标签每 3 小时一枚。

类别构成不放在圆盘上，而是放在清单底部的横向比例条：圆盘只承担“时间”，比例条只承担“构成”，两者不共享角度语义。

### 原则

1. **一件仪器，不是一块仪表盘。** 圆是唯一的主模型，清单是它的可读副本。
2. **时间有形状。** 弧长 = 时长，角度 = 时刻，颜色 = 节奏；不靠图例才能看懂的部分尽量少。
3. **安静的纸，响亮的针。** 大部分表面是墨与纸；红色只留给“现在”、主操作和错误。会议使用梅紫，不占用红色。
4. **精确的细节。** 刻度、对位、数字宽度、圆弧端点都要经得起放大看；不用阴影和渐变掩盖。纸面点阵用 `radial-gradient` 画出 1px 印刷点，视觉上是点阵而不是渐变。
5. **可访问性是结构，不是补丁。** 圆盘上的每个操作都能在清单里用键盘完成；拖动之外永远有单击路径。

## 4. 反模板检查

- 不用暖奶油底 + 高对比衬线 + 陶土色；改用冷骨白、墨黑与信号红。
- 不用“01 / 02 / 03”编号或全大写 eyebrow；页面没有营销分节。
- 不做统一的圆角卡片网格；清单是行，不是卡片。
- 不用渐变、玻璃拟态、彩色阴影；层次靠线宽、字号和留白。
- 不把等宽字体撒在所有小标签上；它只读时间。
- 不在按钮和链接后面统一加“→”；动作词自己说明结果。
- 动效只保留一次圆盘绘制和用户操作反馈，不做逐段上浮。

## 5. 交互模型

- **单击圆盘空白**：在点击时刻放下一段 1 小时的安排。
- **拖动圆盘空白**：拉出一段 15 分钟到 12 小时的时间，松开后打开编辑。
- **点击弧段**：打开编辑，可改标题、时间、类型、备注，或删除。
- **右侧清单**：逐行编辑；完成勾选、时间、时长、备注都可见。清单是圆盘的键盘等价物。
- **日期**：前后箭头、今天按钮、日期选择器。每天独立保存。
- **模板**：深度日、会议日、休息日、示例一天；已有安排时先确认替换。
- **数据**：JSON 导出/导入、ICS 日历导出、打印。所有数据留在 `localStorage`。
- **快捷键**：`N` 新建、`T` 今天、`←/→` 换日、`?` 帮助、`Esc` 关闭。

## 6. 动效与反馈

- 首次载入：圆盘刻度淡入，弧段按顺序绘制一次（`pathLength` + `stroke-dashoffset`），红色指针就位。
- 操作反馈：弧段 hover 加粗、拖拽时出现虚线草稿与时间提示、保存后新弧段绘制、删除后即时移除。
- 时间推进：指针每 30 秒移动一次，不做持续动画。
- `prefers-reduced-motion: reduce` 下取消绘制与位移，只保留即时状态变化。

## 7. 质量底线

- 375 / 768 / 1024 / 1440 四个宽度无横向滚动。
- 正文对比度 ≥ 4.5:1；大字与图形 ≥ 3:1。
- 所有控件有可见焦点；图标按钮有 `aria-label`；弹窗使用原生 `<dialog>`。
- 触控目标 ≥ 44×44px；圆盘拖动有单击替代。
- 离线可用（Service Worker），可安装为 PWA。
- 无第三方运行时依赖；字体本地托管。

## 8. 文案语气

用具体的动词，不用“赋能”“无缝”“高效”。空状态是邀请，不是情绪。错误直接说明发生了什么、怎么改。例如：

- 空状态：“今天还空着。先放下一段专注，或者套用一个现成的节奏。”
- 时间错误：“结束时间要晚于开始时间。”
- 数据说明：“这些安排只保存在这台设备的浏览器里。”
